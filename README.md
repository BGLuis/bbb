# 📖 Sobre

O **bbb. (Bons Brigadeiros & Bolos)** é uma aplicação web moderna, responsiva e de alta performance desenvolvida com Next.js 16, React 19, TypeScript e Tailwind CSS para um ateliê de confeitaria artesanal em São Paulo (Vila Madalena). O projeto traduz com precisão cirúrgica o design do Figma em uma experiência digital acolhedora e intuitiva para encomenda de bolos artesanais, brigadeiros gourmet, docinhos finos e kits festa, integrando seleção de tamanhos, gaveta de sacola interativa com validação de prazos de produção e checkout automatizado via WhatsApp.

# 📋 Motivo

Implementação completa do design de confeitaria artesanal do Figma (*bbb · Confeitaria*), aliando estética visual calorosa inspirada na confeitaria afetiva de família a uma engenharia de ponta que atinge 100% de pontuação em todas as categorias do Google Lighthouse, com imagens otimizadas via `ffmpeg` e zero dependência de JavaScript legado.

# ✨ Recursos & Funcionalidades

- **Design Tokens Fiéis ao Figma**: Paleta calorosa e acolhedora (`cream`, `cocoa`, `terracotta`, `pistachio`), tipografia elegante combinando **Fraunces** e **DM Sans**.
- **Hero Acolhedor com Destaque da Semana**: Chamada principal com badge flutuante do bolo da semana e adição expressa à sacola.
- **Vitrine Dinâmica com Filtros**:
  - Filtros por categoria: *Todos*, *Bolos*, *Brigadeiros*, *Docinhos Finos* e *Kits Festa*.
  - Seletor de tamanhos (P, M, G ou unidades de doces) com atualização instantânea de valor e porções sugeridas.
  - Cards de produto com selos (ex: *"Mais pedido"*, *"Edição limitada"*), tempo de validade e botão de ação direta.
- **Guia Visual de Tamanhos**:
  - Comparativo visual interativo entre Mini (12 cm · 4–6 fatias), P (15 cm · 10–12 fatias), M (20 cm · 20–25 fatias) e G (25 cm · 35–40 fatias) com recomendação de ocasião.
- **Como Encomendar em 4 Passos**:
  - Passo a passo ilustrado: escolha, personalização com recado, antecedência de 48h e entrega ou retirada no ateliê.
- **Sobre o Ateliê & História**:
  - Sessão biográfica homenageando as receitas de família da vó Lurdes com estatísticas de atendimento.
- **Depoimentos Reais & Avaliações**:
  - Depoimentos verificados de clientes com avaliação por estrelas e fotos.
- **FAQ / Dúvidas Frequentes**:
  - Accordion interativo e acessível com respostas claras sobre prazos, conservação, entrega e alergênicos.
- **Sacola de Encomendas & Checkout em 3 Etapas**:
  - **Etapa 1 · Sacola**: Listagem dos itens com seletor de quantidade (+ / -), remoção e cálculo dinâmico de subtotal.
  - **Etapa 2 · Identificação & Agendamento**:
    - Nome e WhatsApp com máscara automática.
    - Validação de data com trava para dias fechados (domingos e segundas) e aviso obrigatório de antecedência mínima de 48 horas para bolos e kits.
    - Seleção de entrega (Vila Madalena, Pinheiros, Perdizes, Jardins e região) ou retirada no ateliê.
    - Campo opcional para recado personalizado na fita ou cartão do bolo.
  - **Etapa 3 · Revisão & Envio WhatsApp**:
    - Prévia visual em tempo real da mensagem formatada que será enviada.
    - Redirecionamento com um clique para a API do WhatsApp com mensagem 100% preenchida.
- **Otimização de Mídia com `ffmpeg`**:
  - 10 imagens comprimidas com `libwebp` com redução de mais de 70% de peso sem perda visual perceptível.
- **Zero Legacy JavaScript**:
  - Browserslist moderno configurado no `package.json` para eliminar polyfills legados do runtime.
- **Acessibilidade WCAG AAA & SEO Avançado**:
  - Link de atalho acessível (*"Pular para o conteúdo principal"*).
  - Contraste de cores testado e validado.
  - Metadados Open Graph, Twitter Cards, Sitemap XML, Robots.txt e Schema estruturado JSON-LD (`Bakery`).

# 💻 Como iniciar

### Requisitos

- [Node.js](https://nodejs.org) (v18+)
- [npm](https://www.npmjs.com) ou [pnpm](https://pnpm.io)

### Instalação

1. Clone o repositório:

   ```sh
   git clone https://github.com/BGLuis/bbb.git
   ```

2. Entre no diretório do projeto:

   ```sh
   cd bbb
   ```

3. Instale as dependências:

   ```sh
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```sh
   npm run dev
   ```

Abra [http://localhost:3000](http://localhost:3000) no navegador para visualizar a aplicação.

### Compilação de Produção

```sh
npm run build
npm run start
```
